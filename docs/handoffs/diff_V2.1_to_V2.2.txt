## 4. LAYER CARD (NOVA FEATURE — CAM IMPORT)

### Nova funkce: build_layer_card(entities, tool_config=None)
  Agreguje entity podle color_index (ACI 0-255) a cross-referencuje
  s dxf_tool_config.json `aci_color_mapping`:
    * Per color: entity_count, total_length, point_count, point_density,
      closed/open ratio, TAC, geometry_types, layers
    * Tool config: cutter_type, base_speed, direction, validation_status
    * is_mapped flag: ma barva mapovani v tool_configu?

  Vystupni struktura v JSON:
    layer_card: {color_count, total_entities_mapped, total_entities_unmapped, colors}

### Nova funkce: write_layer_card_csv(data, out)
  Samostatny CSV soubor `{name}_layer_card.csv` pro primy CAM import.
  Sloupce: color_index, color_name, entity_count, total_length_mm, point_count,
  closed_count, open_count, closed_ratio, total_tac_rad, tac_per_meter,
  point_density_per_meter, min_length_mm, max_length_mm, geometry_types,
  layers, cutter_type, base_speed_mms, direction, validation_status, is_mapped

### Rozsireni write_md():
  Nova sekce `## Layer Card (CAM Import Reference)` s tabulkou barev a toolu.

### Konstanty:
  _ACI_COLOR_NAMES: {0:"ByBlock", 1:"Red", 2:"Yellow", 3:"Green", 4:"Cyan",
                     5:"Blue", 6:"Magenta", 7:"White", 8:"DarkGray", 9:"LightGray",
                     30:"Orange", 52:"Lime", 92:"Azure"} + fallback "ACI_{n}"

## 5. VIZUALIZACE FIX

### Problem (V2.1 bug)
  dxf_indexer_app_v2.py: `import math` bylo uvnitr `else` bloku (spusteno jen
  kdyz NENI nahran soubor). Pri nahrani souboru → NameError pri pouziti
  math.cos/math.sin/math.radians v 2D Viz tabu → crash.

### Oprava (V2.2)
  * `import math` presunut na zacatek souboru (radek 4)
  * Pridany importy do viz tabu: korektni layer_colors, seen_colors tracking

### CLI --viz flag
  Nova funkce _render_png(dxf_path, out_path, semantic, tool_config):
    * Cte DXF primo pres ezdxf (nezavisle na index_dxf)
    * Renderuje vsechny entity barevne dle color_index (stejna paleta)
    * Stock boundary: obdelnik 2900x1220 (carkovane)
    * Zone overlays: horizontalni carkovane cary ze semantic.zones
    * Legenda: color → name → tool_type (pokud je tool_config)
    * Dark theme, aspect='equal', invert Y, 1920x1080, DPI 100
  * `--viz` flag v argparse
  * `--config` flag pro cestu k dxf_tool_config.json

### Rozsireni Streamlit 2D Viz tabu:
  * Legenda s tool typy z layer_card
  * Stock boundary 2900x1220 (carkovany obdelnik)
  * Zone overlay (horizontalni linie ze semantic.zones)
  * Circles vykreslovany s 48 body (hladsi)
  * Arcs: adaptivni segmentace (min 12, ar/0.08)
