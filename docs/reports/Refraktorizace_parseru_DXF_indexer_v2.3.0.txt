## 2. PRINCIPY VERZE 2.4.0 – SNR TRIMMING

### 2.1 Odstranit informační šum (nikoli „omezit na X kB“)

**Co je šum:**
- Duplicitní body na přímkách (kolinearita).
- Aproximace kružnic polygony (108 bodů místo 1 kružnice).
- Úplné seznamy vrcholů pro každou entitu (pro LLM zbytečné).
- Detailní `proximity_matrix` (1936 hodnot pro 44 tvarů).
- `nesting_tree` redundantní s `containment` hranami.

**Co je signál (zachovat):**
- Agregované statistiky (délka, plocha, počet bodů, TAC).
- `tool_assignments`, `cutting_time_estimate`, `zones`, `layer_card`.
- `shape_groups` (již kompaktní).
- `semantic_analysis.narrative_summary`.

**Implementační poznámka pro developera:**  
Výstupní JSON by měl být čitelný pro LLM a zároveň obsahovat pouze data, která **mění rozhodování**. Pokud odstranění určité položky nezmění výsledné doporučení (např. panel_type, tool assignment), je položka šum.

## 3. TOPOLOGICKÁ HIERARCHIE (AST STROM)

### 3.1 Detekce "Mother Board" (hlavní deska / polotovar)

**Definice:** Entita s největší plochou v rámci spatial clusteru, jejíž bounding box obsahuje bounding boxy jiných entit.

**Výstup (místo plochého seznamu):**

```json
{
  "nesting_tree": {
    "mother_board_id": "E_0068",
    "bbox_mm": [3112, 11661, 4312, 14061],
    "children": [
      {
        "id": "E_0050",
        "type": "cutout",
        "area_mm2": 74832,
        "depth": 1
      },
      {
        "id": "E_0051",
        "type": "cutout",
        "area_mm2": 74536,
        "depth": 1,
        "children": [...]  // vnořené kapsy
      }
    ]
  }
}
```

### 3.2 Automatické přiřazení CAM operace na základě hloubky

| Hloubka | Typ entity | Operace |
|---------|------------|---------|
| 0 | Mother board | (ignorovat, není řezána) |
| 1 | Vnější obrys | `outer_format` |
| 2+ | Vnitřní kapsa | `slot_milling` + `z_hop_required = true` |

## 4. KINEMATICKÁ KOREKCE – NENÍ V TÉTO ITERACI

**Poznámka developera:**  
Výpočet přejezdů (travel time) a akceleračních penalizací vyžaduje reálné testování na konkrétním stroji. V2.4.0 se omezí na **trimmování vstupních dat** a **přesný výpočet čistého řezu** (již implementováno). Travel time bude přidáno ve verzi 2.5.0 po terénním výzkumu.

## 5. ČTYŘI TOPOLOGICKÉ PROFILY A TRIGGERY

| Profil | Trigger | Fallback / Speciální handling |
|--------|---------|-------------------------------|
| **production_nesting** | `closed_ratio > 0.95`, `entity_count > 20` | `outer_format` pro všechny, TSP pro přejezdy (v2.5.0) |
| **hybrid_nesting** | `0.7 < closed_ratio < 0.95`, `open_path_count > 0` | Separátní ACI mapování (vibrate vs v-slot) |
| **matrix_perforation** | `closed_ratio == 1.0`, `point_density > 100`, `mean_area_per_entity < 10000` | **Vnitřní entity → slot_milling** (ne outer_format) |
| **artistic_engraving** | `closed_ratio < 0.1`, `entity_count > 500` | Vypnout ortogonalitu, **engraving** mód, lokální klastrování |

**Implementace triggerů:**  
Každý trigger je podmínka, která se vyhodnotí po agregaci základních statistik. Pokud je splněna, přepíše se výchozí chování (např. `outer_format` → `slot_milling`).

## 6. AKČNÍ BODY PRO VÝVOJÁŘE (PRIORITY – BEZ ARBITRÁRNÍCH LIMITŮ)

### 🔴 Priorita 1 (Kritická – blokuje nasazení)

- [ ] **Light JSON** – odstranit `vertices`, `proximity_matrix`, `nesting_tree` z výchozího výstupu. Developer rozhodne o kompromisu mezi informací a velikostí.
- [ ] **Implementovat RDP zjednodušení** pro všechny polyline (epsilon = 0.01 mm).
- [ ] **Zachovat typ CIRCLE** – neaproximovat.

### 🟠 Priorita 2 (Vysoká – zlepšení SNR)

- [ ] **KD‑Tree pro proximity** – nahradit $O(N^2)$ (nutné pro botanic_vse s 1000+ entitami).
- [ ] **Containment tree** – detekce mother board a hloubky vnoření.
- [ ] **Trigger pro `matrix_perforation`** – změna `outer_format` na `slot_milling` pro vnitřní entity.

### 🟡 Priorita 3 (Střední – doladění)

- [ ] **Opravit `perpendicular_pairs`** – detekce i neprotínajících se kolmic.
- [ ] **Zóny** – minimálně 3 entity pro detekci, normalizace `regularity_score` na 0–1.
- [ ] **`min_feature_width_mm`** – odhad z mezer mezi paralelními hranami (např. 10 mm).

### ⚪ Priorita 4 (Nízká – nice to have)

- [ ] **Delta + varint komprese** pro full JSON (pokud bude potřeba archivace).
- [ ] **CSV jednotky** – přejmenovat `zone_lengths_mean` → `zone_lengths_mean_mm`.
- [ ] **`has_arcs` detekce** pro kružnice (nyní false i u CIRCLE).
